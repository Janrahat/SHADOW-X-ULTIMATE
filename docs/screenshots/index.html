Every image below is a render of real output captured from the tool. The raw ANSI streams were recorded by running the CLI and converted to SVG with their escape codes intact — nothing here is a mockup or a hand-drawn fake terminal.

Platform note. These captures were taken on Debian Linux, not on an Android device. The tool detects Termux and adapts (no traceroute binary, no root, different interface enumeration), so a Termux run shows a Termux badge and fewer available capabilities — the layout and colours are identical. Only test systems you own or are explicitly authorized to test.
